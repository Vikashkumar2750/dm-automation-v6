# AI Agent guide

The AI Agent answers **DMs only**, and only when no keyword rule and no flow replied. It can never send over your existing automations.

## How it works
- When a DM arrives, the agent first checks your keyword rules, then flows. Only if both stayed silent does it answer.
- It answers **only from your knowledge base** — it never invents prices or policies.
- Before replying it checks how sure it is. Below your handover threshold it stays quiet and the chat goes to your team in the Inbox.
- It also labels every chat with **intent** (price, support, order…), **sentiment** (positive, neutral, negative) and a **lead score**, so hot buyers are easy to find in Inbox and Contacts.

## How to use
1. Open **Automations → AI agent** and switch it **on** for this workspace.
2. Fill in the **knowledge base**: products, prices, delivery, timings, policies, links. The agent only answers from this text.
3. Set the **tone** (friendly, professional…) and the language style.
4. Choose a **handover threshold**: if the agent is less sure than this, it does not reply and the chat goes to your team in the Inbox.
5. Optional: **label-only mode** — the agent just labels chats (intent, sentiment, lead score) without replying. Good for trying it safely.
6. Press **Save**.

## Test it safely
Use the test box on the right side to type a sample message and see the answer before going live. It never sends anything.

## Good practice
- Keep the knowledge base factual and up to date.
- Start with a higher handover threshold, then lower it as you trust the answers.
- Safety limits, quiet hours and daily caps apply as usual.
